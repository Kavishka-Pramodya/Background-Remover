AURA STORE — LOCAL AI STUDIO ENGINE FOR STORE OWNERS (Windows & Mac)
===================================================================

Congratulations on setting up your Aura Store AI Photo Studio!

WHY RUN LOCALLY?
1. 100% Free Forever: No monthly cloud server hosting bills.
2. Unlimited Photos: Process hundreds of product photos without throttling.
3. No Memory Limits: Runs smoothly using your computer's RAM/CPU.
4. Fast: Takes ~1-2 seconds per image (Super-fast on Apple Silicon M1/M2/M3/M4).

HOW TO RUN:

[On Windows]:
1. Double-click `start_local_studio.bat`.
2. It will automatically check Python and launch the AI server on:
   http://127.0.0.1:8000
3. Keep the Command Prompt window open.

[On Mac (MacBook / iMac / Mac mini)]:
1. Double-click `start_local_studio.command` (or in Terminal run `bash start_local_studio.sh`).
2. It will automatically launch the AI server on:
   http://127.0.0.1:8000
3. Keep the Terminal window open.

NEXT STEPS IN WEB BROWSER:
1. Open your live online store:
   https://background-remover-frontend-delta.vercel.app/
2. Go to "Store Owner Portal" -> The badge will show green:
   [🟢 Local AI Engine Active]
3. Upload your phone photo, pick a background template, and click:
   "Generate Studio Image"
4. Click "Publish Product to Storefront" to put it live on your store!

TROUBLESHOOTING:
- If Python is not installed:
  * Windows: Download Python 3.10+ from https://www.python.org/ (Check "Add Python to PATH")
  * Mac: Install Python via https://www.python.org/ or run: brew install python
