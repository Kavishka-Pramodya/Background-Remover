AURA STORE — LOCAL AI STUDIO ENGINE FOR STORE OWNERS
===================================================================

Congratulations on setting up your Aura Store AI Photo Studio!

WHY RUN LOCALLY?
1. 100% Free Forever: No monthly cloud server hosting bills.
2. Unlimited Photos: Process hundreds of product photos without throttling.
3. No Memory Limits: Runs smoothly using your computer's RAM/CPU.
4. Fast: Takes ~1-2 seconds per image.

HOW TO RUN:
1. Double-click `start_local_studio.bat`.
2. It will automatically check Python and launch the AI server on:
   http://127.0.0.1:8000
3. Keep the terminal window open.
4. Open your live online store:
   https://background-remover-frontend-delta.vercel.app/
5. Go to "Store Owner Portal" -> The badge will show green:
   [🟢 Local AI Engine Active]
6. Upload your phone photo, pick a background template, and click:
   "Generate Studio Image"
7. Click "Publish Product to Storefront" to put it live on your store!

TROUBLESHOOTING:
- If Python is not installed, download Python 3.10+ from https://www.python.org/
  Make sure to tick the checkbox "Add Python to PATH" during installation.
- If you have any questions, you can contact your store developer.
