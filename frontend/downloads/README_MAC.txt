Thank you for downloading the Aura Local AI Engine for Mac!

QUICK START:
1. Extract all files from this ZIP into any folder on your Mac (e.g. Applications or Desktop).
2. Double-click "start_local_studio.command" (or in Terminal run "bash start_local_studio.sh").

WHAT HAPPENS:
- First Launch (One-Time Setup):
  Sets up an isolated virtual environment and installs AI segmentation packages.
  This takes ~1-2 minutes on the first run.
  A ".installed" marker file will be created.

- Every Next Launch:
  Double-clicking "start_local_studio.command" starts the engine
  instantly in less than 1 second! Zero reinstalling required.

3. Keep the Terminal window open while creating product images.
4. Your browser will automatically open your store:
   https://background-remover-frontend-delta.vercel.app/
   The badge in Merchant Studio will display:
   "🟢 Studio Engine Online"

SYSTEM REQUIREMENTS:
- macOS 11 (Big Sur), macOS 12 (Monterey), macOS 13 (Ventura), macOS 14 (Sonoma), or newer.
- Apple Silicon (M1, M2, M3, M4) or Intel Mac.
- Python 3.10+ (install via https://www.python.org/ or run 'brew install python').
